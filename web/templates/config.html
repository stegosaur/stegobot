AI (Ollama)

How to reach Ollama, shared by both the ollama [nick] command and the automatic AI Watchlist replies below. Queries reach a remote Ollama server over an SSH tunnel opened on demand and closed right after, and always run one at a time in the background so a slow response never blocks the bot — if several trigger at once they're answered in order. Per-user line count and system prompt live on each AI Watchlist entry below, not here — different watched users can get different context.
